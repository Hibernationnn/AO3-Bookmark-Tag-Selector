# AO3-Book-Tag-Selector
为 AO3 书签编辑页面添加个人标签库、标签搜索、快捷添加标签块、自动记录确认标签功能。
一个用于 Archive of Our Own（AO3）书签编辑页面 的标签管理填空脚本。它可以创建一个属于你自己的标签库，并快速将常用标签添加到 AO3 书签中。无需服务器，不收集数据，所有标签数据仅保存在你的浏览器本地。

功能：
- AO3 Bookmarker's Tags 导入个人标签库
- 我的标签搜索
- 点击候选标签直接生成 AO3 标签块
- 自动记录手动确认的新标签
- 支持 Enter 和 AO3 自动补全确认

使用：
1. 打开 我的书签页面
2. 在Filter- Bookmarker's Tags 点击“导入到我的标签”
3. 在编辑书签“我的标签”区域点击标签即可快速添加
